# Sharpen

只在用户显式调用时执行。用户要的是这个任务更深的版本，不是更大的版本。改写前先做四件事：

1. 说出这个领域的顶尖从业者在这里会做、而用户没要求的事。
2. 说出他们会从哪份最原始的材料入手，而不是用户手上已经被消化过的材料。
3. 说出他们会用的具体方法和工具。
4. 说出除了你和用户之外，什么能证明结果是对的。

然后把用户的请求改写成正好要这些东西的版本。改写后的请求带上目标、一个能判过或不过的完成条件、想看的证据、已知线索和真实约束；原请求没给且推不出的项写 Unknown。

属于用户的选择保持开放，不替用户决定。本次只交付四项回答和改写后的请求，不执行任务，不修改文件。
