# 前向验证案例

以[停止回合的 Spec](../../to-tickets/references/stop-turn/spec.md) 为独立来源。给执行者场景与不同的既有证据，按其实际选择核对。

| 输入 | 应交回的决定和理由 |
| --- | --- |
| 已有 `node check.cjs all`，从回合入口停止并读回状态与列表 | 复用。该断言能杀死“显示已停止但清空第一段”的变异体。独立预期来自 S1。 |
| 只有内部停止函数的调用计数 | 补强。保留已生成「第一段」的前提，操作后读回状态和原内容。只看调用次数杀不死清空结果的变异体。 |
| 用户只确认可以停止，还没决定已有内容如何处理 | 待裁决。把保留还是清除交给需求作者，记录原票号。不得从当前返回值推断。 |

可在[例子项目](../../to-tickets/references/stop-turn/example/check.cjs)的临时副本中把状态实现为 `stopped`、结果保持为空。运行 `node check.cjs status` 应通过，`node check.cjs all` 应在原「第一段」的断言处失败。
