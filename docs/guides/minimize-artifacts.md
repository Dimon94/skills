# Minimize Dverity Artifacts

Keep only evidence with a named owner and consumer.

- Use Git commits and provider readback for delivery evidence.
- Let `postmortem` write only confirmed reusable lessons or explicitly requested records.
- Let `dverity-research` write only reusable source-backed research.
- Keep temporary probes, logs, scratch packets, and generated intermediates outside durable truth.
- Do not create another product contract; point to [DVERITY.md](../../DVERITY.md).

If an artifact has no durable decision, audit, recurrence, or consumer, delete it.
