## 失败与边界

Claude 首次启动器参数错误，未进入模型会话；修正空 MCP 配置与参数分隔后，用同一 CLI 重跑通过。Pi 首次沿用默认 `magpie/junbo/gpt-6.1-sol` 返回 HTTP 402 月积分超限，未执行工具；CLI 仍退出 0，故校验器同时检查模型错误与真实工具记录，不把退出码当作通过。

本轮没有更改默认 provider。需要立即在可用 provider 启动 Pi 时，本轮通过的选择为 `pi --provider openai-codex --model gpt-6.1-sol`。这不是额外安装步骤；新会话会发现已部署的 Skill 与扩展，已打开会话的 Skill 索引需按宿主资源刷新机制更新。

本轮证明上述工具路径的真实投递、正负对照和去重，不证明测试质量提升率。SubagentStart、压缩后重提醒、并发持久化时序、完整原始 hook stdin、退出码 1 的 TUI 表现与跨版本信任仍不在本轮验收内。
